# Region-owned native file drops

The routing provider owns native browser `Files` events and region selection. A consumer owns whether its current target can accept a batch, the visible invitation and the operation performed after a drop. Chat image validation remains in InputBar; manager uploads remain in the manager. Keeping that direction explicit permits either consumer and the routing plugin to be removed independently.

One composed-path match receives each gesture. A nested refusing target blocks an outer accepting target, so a drop cannot silently change destination. Outside registered regions the provider only prevents native file navigation. Text and internal application drags do not enter this dispatch path. Hover callbacks and intake failures are contained at the consumer callback boundary, and every registration has an idempotent disposer.

The Host adapter declares one optional Conversation seat and supplies existing localized image copy and intake callbacks. It removes the attachment renderer's drop listeners and overlay; the new plugin owns the Chat adapter and illustration. The independent receipt covers that exact adapter, including the earlier conversation-region id support. Reversal restores the recorded Host baseline; plugin disable with the adapter retained leaves the seat empty. Installation and live activation have separate evidence in LOG.
